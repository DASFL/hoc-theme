# Переключение темы

Приложение на React и TypeScript. Родительский компонент переключает светлую и тёмную темы.
HOC withTheme передаёт тему и остальные props карточке. Context API не используется.

Для запуска:

```bash
npm install
npm run dev
```

Откройте адрес из терминала и нажмите кнопку переключения темы.
